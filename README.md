# CouncilApp

**CouncilApp** — приложение для организации работы Совета обучающихся школы.

Проект создавался для решения реальной задачи: упрощения работы Совета, хранения информации об участниках, планирования мероприятий и ведения внутренней активности.

## О проекте

Приложение предназначено для участников Совета обучающихся.

Основная идея — объединить основные рабочие инструменты Совета в одном приложении:

* участники Совета;
* календарь;
* мероприятия;
* посещаемость;
* система баллов и история активности.

Проект **ещё не завершён и находится в процессе разработки**.

## Технологии

* Python
* Flet — графический интерфейс
* SQLite — планируемое постоянное хранение данных
* Git / GitHub — контроль версий

## Реализовано

### Участники

* список участников Совета;
* карточки участников;
* профили участников;
* фотографии;
* должность и класс;
* дата рождения;
* баллы;
* интересы и качества;
* история активности;
* добавление баллов за активность.

### Календарь

* отображение календаря по месяцам;
* переключение между месяцами;
* добавление мероприятий к определённой дате;
* добавление фотографии;
* просмотр информации о мероприятии;
* удаление мероприятий.

### Мероприятия

* отдельный раздел мероприятий;
* создание мероприятия;
* выбор даты;
* добавление фотографии.

### Посещаемость

Раздел предназначен для ведения посещаемости заседаний Совета.

Данный функционал ещё находится в разработке. В дальнейшем планируется связать посещаемость с записями заседаний и хранить информацию о том, что обсуждалось на конкретной встрече.

В процессе разработки использовался ChatGPT как AI-помощник.

AI применялся для:

* поиска причин ошибок;
* объяснения Python и Flet;
* изучения API;
* поиска вариантов реализации отдельных функций;
* помощи при отладке;
* улучшения отдельных элементов интерфейса.

При этом структура приложения, требования к функциональности и основная логика определялись мной. Полученный от AI код адаптировался и дорабатывался под конкретную версию Flet и архитектуру проекта.

## Запуск

### Требования

* Python 3.x
* Flet 0.86.5

### Установка

Клонировать репозиторий:

```bash
git clone https://github.com/ktyzwqr32tdg/CouncilApp.git
cd CouncilApp
```

Установить Flet:

```bash
pip install flet==0.86.5
```

Запустить приложение:

```bash
python main.py
```

# CouncilApp

**CouncilApp** — приложение для организации работы Совета обучающихся школы.

Проект создавался для решения реальной задачи: упрощения работы Совета, хранения информации об участниках, планирования мероприятий и ведения внутренней активности.

## О проекте

Приложение предназначено для участников Совета обучающихся.

Основная идея — объединить основные рабочие инструменты Совета в одном приложении:

* участники Совета;
* календарь;
* мероприятия;
* посещаемость;
* система баллов и история активности.

Проект **ещё не завершён и находится в процессе разработки**.

## Технологии

* Python
* Flet 0.86.5
* SQLite — планируется для постоянного хранения данных
* Git / GitHub — контроль версий

## Реализовано

### Участники

* список участников Совета;
* карточки участников;
* профили участников;
* фотографии;
* должность и класс;
* дата рождения;
* баллы;
* интересы и качества;
* история активности;
* добавление баллов за активность.

### Календарь

* отображение календаря по месяцам;
* переключение между месяцами;
* добавление мероприятий к определённой дате;
* добавление фотографии;
* просмотр информации о мероприятии;
* удаление мероприятий.

### Мероприятия

* отдельный раздел мероприятий;
* создание мероприятия;
* выбор даты;
* добавление фотографии.

### Посещаемость

Раздел предназначен для ведения посещаемости заседаний Совета.

Функционал находится в разработке. В дальнейшем планируется связать посещаемость с записями заседаний и хранить информацию о том, что обсуждалось на конкретной встрече.

## Запуск приложения

### Требования

* Windows
* Python 3.x
* Flet 0.86.5

### Установка

Клонировать репозиторий:

```powershell
git clone https://github.com/ktyzwqr32tdg/CouncilApp.git
cd CouncilApp
```

Создать виртуальное окружение:

```powershell
python -m venv .venv
```

Активировать виртуальное окружение:

```powershell
.\.venv\Scripts\activate
```

Установить Flet:

```powershell
pip install flet==0.86.5
```

### Запуск

Для запуска приложения выполнить:

```powershell
C:\CouncilApp\.venv\Scripts\python.exe main.py
```

После выполнения команды откроется графическое приложение CouncilApp.

> Если проект находится не в `C:\CouncilApp`, замените путь `C:\CouncilApp` на путь к папке проекта.
